# Nini's JobTracker

A personal career and job application tracker designed to help you organize your job search in one place.

## ✨ Features

- **Job Tracking** — Organize and monitor your job applications.
- **Career Profile** — Keep your career information organized.
- **Clean Interface** — A minimal, Midnight Black-inspired design.
- **Responsive Layout** — Designed for a clean and convenient experience.

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript

## 🚀 Getting Started

1. Clone this repository:

   ```bash
   git clone https://github.com/yadavnidhi13/JOB-STRACKER.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser to run the project.
